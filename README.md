# David Baker (MeatIsMurder) – Portfolio

A lightweight static portfolio using plain HTML, CSS and a tiny bit of vanilla JS. No build step; total size is well under 1 MB, so it fits easily in 15 MB of free web space.

## Deploy
Upload `index.html`, `style.css`, `script.js` and the `images/` folder to your web space (e.g. by FTP).

## Extending
- Screenshots: add images to `images/` and swap a `.panel` preview for an `<img class="preview shot">`.
- CV: add `cv.pdf` and uncomment/add a link in the Contact section.
