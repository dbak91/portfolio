# David Baker (MeatIsMurder) – Portfolio

A lightweight static portfolio: a landing page plus detail pages for each featured project. Plain HTML, CSS and a tiny bit of vanilla JS. No build step; total size is well under 1 MB, so it fits easily in 15 MB of free web space.

## Deploy
Upload `index.html`, `assets/`, `projects/` and `images/` to your web space (e.g. by FTP), keeping the folder structure.

## Extending
- Screenshots: add images to `images/` and reference them from the relevant `projects/*.html` page.
- CV: add `cv.pdf` and link it in the Contact section of `index.html`.
